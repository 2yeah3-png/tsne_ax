## 저장소에 올릴 파일

다음 파일을 저장소 최상위에 함께 업로드합니다. ZIP 파일은 먼저 압축을 풉니다.

- index.html
- tsne-ai-cae-seminar-20261119.ics
- .nojekyll
- README.md (선택)

## GitHub Pages 설정

1. 저장소의 Settings → Pages로 이동합니다.
2. Build and deployment의 Source를 Deploy from a branch로 선택합니다.
3. 업로드한 브랜치(일반적으로 main)와 /(root)를 선택하고 Save를 누릅니다.
4. 배포 완료 후 Pages 설정 화면의 Visit site 주소를 엽니다.
5. 해당 웹페이지 주소를 QR에 연결합니다.

GitHub Pages 사용 가능 여부는 계정 요금제 및 저장소 공개 설정에 따라 달라질 수 있습니다. 무료 개인 계정에서는 Public 저장소로 사용하는 것이 일반적입니다.

## 캘린더

Google 캘린더 버튼은 Android와 iPhone의 Google 캘린더에서 사용할 수 있습니다. iPhone 기본 캘린더는 Safari에서 .ics 파일을 열어 추가합니다. 실제 일정 등록은 고객이 저장 또는 추가를 누를 때 완료됩니다.

캘린더 파일은 index.html과 같은 폴더에 두어야 합니다. 상대 경로를 사용하므로 저장소 이름이 바뀌어도 함께 작동합니다. GitHub Pages에 별도 서버나 빌드 설치는 필요하지 않습니다.
